# 10. GDD — 머지 (케시카스 머지)

- **문서 버전**: Vol.1 (코어 루프 한정)
- **최종 수정**: 2026-06-25
- **범위**: 본 문서는 **코어 루프만** 다룬다. 콤보 · 특수블록 · 사운드 · 연출 등은 Vol.2 이후.

---

## 1. 게임 개요
케시카스 캐릭터를 위에서 떨어뜨려, 같은 종류끼리 닿으면 한 단계 위 캐릭터로 합체한다. 플레이필드가 가득 차 상단 경계(데드라인)를 넘으면 종료. 합체로 점수를 쌓고 최고점을 노린다.

## 2. 코어 루프
1. 다음에 떨어질 케시카스가 상단에 대기 (미리보기 제공)
2. 플레이어가 좌우 위치를 정해 드롭
3. 낙하 → 물리로 쌓임
4. 같은 종류끼리 접촉 시 합체 → 한 단계 위 캐릭터 1개 생성 + 점수 획득
5. 반복. 데드라인을 일정 시간 넘으면 게임오버
6. 최고점 갱신 시 서버(Supabase)에 기록

## 3. 화면 구성 (세로 모바일 기준)
```
┌─────────────────────┐
│  (1)    (2)    (3)   │
├─────────────────────┤  <- (4)
│                     │
│        (5)          │
│                     │
│   ●  ▲   ◆          │
│  ●●  ▲▲  ◆◆         │
├─────────────────────┤
│        (6)          │
└─────────────────────┘
```
- **(1)** 점수  **(2)** 최고점  **(3)** NEXT 미리보기
- **(4)** 데드라인 (이 위로 넘으면 위험)
- **(5)** 플레이필드 (좌우 벽 + 바닥, 물리 컨테이너)
- **(6)** 하단 (Vol.2 기능버튼 예약)

> **현재 구현 차이(`15` 참조)**: 점수는 상단 중앙(48px), 최고점은 **좌상단**(`ベスト N`, 상시 표시·실시간 갱신), NEXT는 우상단. (1)(2) 위치가 GDD 도식과 약간 다르나 의미는 동일.

### 3.1 로딩 / 타이틀 화면
- **배경색**: `#fce0e3` (파스텔 핑크) — 전 화면 공통 기본 배경
- **로딩(PreloadScene)**: 핑크 배경 + 중앙 케시카스 1마리 통통 바운스(절차적 애니, `30` 계층1) + 하단 심플 프로그레스(도트/바) + 로고 작게
- **타이틀(TitleScene)** ※미구현, ④에서 제작
  - 상단: 타이틀 로고
  - 중앙: 큼직한 둥근 **START** 버튼 → 아래 작은 **랭킹** 버튼
  - 우상단: 언어 선택(5개 언어, `25` 연계)
  - 구석: 최고점 표시 + 아이들 케시카스 1~2마리 꼬물 바운스
  - 톤: 파스텔 · 둥근 폰트 · 바운스
  - ※ 함께 처리: 랭킹 조회 표시(`fetchTop`), 이름 입력 UX(`50` §7.2), L10N 언어선택(detectLocale 연결)
- **에셋 방침**: 기존 케시카스 일러스트 활용. 바운스용 캐릭터 몇 종만 이미지에서 분리해 개별 스프라이트로(`30` 입력규격·네이밍). 글자 없는 캐릭터는 전 언어 공통.

## 4. 조작
- 터치 드래그 또는 탭으로 드롭 위치(가로)를 지정
- 손을 떼거나 탭하면 해당 위치에서 낙하
- 한 번에 1개씩, 낙하 후 짧은 쿨다운

## 5. 합체 사다리 (11단 · 올-동물)

- **드롭 가능 단계**: 1~3단만 무작위 드롭. 나머지는 합체로만 등장.
- **확장 훅**: 사다리는 데이터(`data/merge_ladder.ts`)로 분리. 캐릭터 추가 = 데이터 1줄.
- **표시명은 L10N 키**: `char.<key>.name` (예: `char.bee.name`). 한국어/중국어 표기는 로케일 파일에서. (`25`)
- **예비 동물**(교체/Phase 3 도감용): トナカイ(reindeer) · きょ〜りゅ〜(dinosaur) · サンタ · あかおに · あおおに 등.
- **검토 포인트**: ① 11종 구성 이대로 vs 교체 ② 크기 서열 ③ 드롭 단계(1~3)

## 6. 점수
- 합체마다 점수 획득. 상위 단계 합체일수록 고득점.
- 누적 점수 = 현재 점수. 게임오버 시점 점수가 해당 판 결과.
- 최고점만 랭킹 대상 (서버 전송).
- 구체 점수표는 Vol.2에서 밸런싱.

## 7. 게임오버
- 오브젝트가 데드라인을 넘은 상태로 일정 시간(예: 1~2초) 지속되면 종료.
- 종료 화면: 최종 점수 / 최고점 / 다시하기 / (랭킹 보기).
- ※ 현재 구현: 점수 + 최고점 + 다시하기 표시. 랭킹 보기는 ④에서 추가.

## 8. 서버 연동 포인트 (Phase 1)
**로그인 화면 없음.** 익명 인증은 백그라운드 자동(사용자는 아무것도 안 함). 랭킹은 "내 최고점 갱신 시에만" 전송.

랭킹 갱신 흐름:
1. 플레이 → 점수
2. 게임오버 시 이번 점수 vs **로컬 최고점**(localStorage 저장값) 비교
3. 로컬 최고점 갱신일 때만 → 서버 전송 (아니면 전송 안 함 = egress 절약)
4. 서버 전송 = `{이름, 점수}` upsert (익명 user_id로 **기기당 1행**)
5. 랭킹 = best 내림차순 상위 N 조회

이름 입력 UX:
- **최초 1회만** 입력(랭킹에 처음 오를 때) → localStorage 기억 → 이후 자동 사용
- 설정에서 이름 변경 가능
- ※ 현재는 `name.default`(ja=`匿名のひよこちゃん`) 고정 전송. 입력 UI는 ④ 타이틀.
- 상세 스키마 · RLS · 키프얼라이브는 `50_서버사양`.

## 9. 확장성 설계
- 합체 사다리 = 데이터 분리 → 캐릭터 / 단계 추가 용이
- 라인 교체(디저트 → 식사) = 새 모드로 재사용
- 스킨 / 이벤트(예: サンタ · トナカイ 크리스마스 라인) 삽입 가능
