### 3.1 U10 상세 — 히트영역 정합 (★ 회귀 필수)
**배경**: Cycle 5a~5b 동안 START 버튼의 히트영역이 그려진 영역과 **절반만큼 어긋나** 있었다. 원인은 Phaser 4 Container의 `displayOrigin` 이중 적용(`20` §7.1 / `99` §6.1).
- 그려진 버튼: `x 115~335 / y 398~482`
- 당시 실제 반응 영역: `x 5~225 / y 356~440` (겹침 = 버튼 면적의 **1/4**)
- 체감 증상: "여러 번 눌러야 반응한다" + "버튼 바깥을 눌러도 반응한다"

**검사 항목 (버튼을 새로 만들거나 수정할 때마다 반드시 수행)**

| # | 동작 | 기대 결과 |
|---|---|---|
| U10-1 | 버튼 **오른쪽 아래 모서리** 탭 | 정상 반응 |
| U10-2 | 버튼 **왼쪽 위 바깥** 빈 공간 탭 | **아무 일도 일어나지 않음** |
| U10-3 | 버튼 아무 곳이나 **1회** 탭 | 1회에 반응 (반복 탭 불필요) |

> **적용 대상**: 현재 START. **5f 이후 추가되는 🌐(bee) · 🏆(whaleshark) 버튼에도 동일하게 수행할 것.**

### 7.1 미번역 키 검출 스크립트
```javascript
// jaのキー集合と各言語のキー集合を比較し、未翻訳キーを洗い出す
const fs = require('fs');
const load = (l) => Object.keys(JSON.parse(fs.readFileSync(`./src/locales/${l}.json`)));
const ja = load('ja');                              // 基準キー
for (const l of ['en', 'ko', 'zh-CN', 'zh-TW']) {
  const have = new Set(load(l));
  const missing = ja.filter((k) => !have.has(k));   // jaにあって当該言語に無いキー
  console.log(l, 'missing:', missing.length, missing);
}
```

## 8. 성능 테스트
- 모바일에서 오브젝트 다수(20~40개) 적재 시 프레임 유지(체감 끊김 없음)
- **벽지 티커 상시 애니메이션(띠 30개)이 프레임에 영향을 주지 않는지** — `will-change: transform`로 GPU 합성 유도. **다만 `will-change`가 30개 붙어 있어 데스크톱에서 레이어 메모리가 커질 수 있다(추정 100MB↑).** 저사양 기기 실측 필요
  - 측정법: DevTools → More tools → **Layers** 패널에서 레이어 수/메모리 확인
  - 격리법: `index.html`의 `data-bands`를 `2`로 낮추고 새로고침 → 체감 비교
- 메모리 누수(장시간 플레이) 확인
- 초기 로딩 시간(에셋/폰트) 허용 범위
  - **효과음 실측**: drop 12KB / merge 57KB / gameover 107KB = 합계 약 177KB → 병목 아님

## 9. 코드 규칙 검증
### 9.1 한글-금지 (코드 로직)
```python
import re, glob
# コードロジック(ts/sql/yaml/sh)にハングルが混入していないか検査する
# ※ locales/*.json は翻訳データのため対象外
# ※ index.html の data-words も表示データのため対象外（.htmlはそもそも走査しない）
HANGUL = re.compile(r'[\uac00-\ud7a3\u3130-\u318f]')
CODE = ('.ts', '.sql', '.yaml', '.yml', '.sh')
bad = 0
for f in glob.glob('src/**/*', recursive=True):
    if not f.endswith(CODE):
        continue
    for i, line in enumerate(open(f, encoding='utf-8'), 1):
        if HANGUL.search(line):
            print(f, i, line.strip()); bad += 1
print('violations:', bad)   # 0でなければNG
```
- 기대: violations 0
- **화이트리스트(검사 제외)**: `src/locales/*.json`(번역 데이터), `index.html`의 `data-words`(벽지 표시 데이터). 상세 `25` §11
- **주의**: `.html`을 `CODE` 튜플에 추가하지 말 것. 추가하면 `#케시카스`가 오탐된다.
- **주의**: PowerShell 사용 시 `findstr /R "[가-힣]"`는 **금지**. 콘솔 코드페이지 변환으로 `??`(nullish) 줄을 전부 오탐한다. `Select-String -Pattern '[\uAC00-\uD7A3\u3130-\u318F]'`를 쓴다.
