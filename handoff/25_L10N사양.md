# 25. L10N 사양 (다국어)

- **문서 버전**: v1.2
- **최종 수정**: 2026-07-09
- **범위**: 텍스트 · 이미지 다국어 처리 전반. Phase 1부터 모든 표시 요소에 적용.

---

## 1. 목적 / 원칙
- **모든 표시 텍스트는 L10N 키로** 처리. 코드 · 이미지에 문자열 하드코딩 금지.
- **이미지**: 글자 없는 그림(캔디 · 아이스 등)은 전 언어 공통. 글자 박힌 이미지만 언어별 분기(최소화). 가능하면 글자는 폰트 렌더링으로 빼서 텍스트 L10N 하나로 해결.
- **예외 = 다언어 동시 표시**: 로케일에 따라 "전환"되는 게 아니라 여러 언어를 **한 화면에 동시 노출**하는 장식(예: 사선 티커 벽지)은 L10N 키 대상이 아니다. §13 참조.

## 2. 지원 언어
| 키(BCP-47) | 언어 | 비고 |
|---|---|---|
| `ja` | 日本語 | 케시카스 원본, **기본 / 폴백** |
| `en` | English | |
| `ko` | 한국어 | |
| `zh-CN` | 简体中文 | 중국 본토 |
| `zh-TW` | 繁體中文 | 타이완 |

- **폴백 체인**: 요청 언어 키 없음 → `ja`
- 키 부재 시에도 앱이 깨지지 않고 `ja` 문자열로 동작.

## 3. 키 네이밍 규칙
- 형식: `<도메인>.<요소>` — 소문자 · 점 구분
- 화면/UI: `title.start`, `game.score`, `result.retry`, `common.ok`, `common.cancel`
- 캐릭터: `char.<key>.name` (도감 대비 `char.<key>.desc`도 예약)
- 규칙: 키는 의미 기반(언어 중립). 값만 번역.

## 4. 파일 구조
```
src/locales/
  ja.json     (master = 기준 키 집합)
  en.json
  ko.json
  zh-CN.json
  zh-TW.json
```
- `ja.json`이 **키의 source of truth**. 다른 언어는 ja의 키 집합을 100% 따른다.
- 키 추가 시 ja 먼저 → 나머지 언어 채움(미번역은 ja 폴백으로 동작).
- **현재 키 수: 18** (UI 4 + `char.<key>.name` 11 + `game.best` + `name.default` + `title.start`)

## 6. i18n 구현 (경량 · 의존성 0)
Phaser엔 i18n 내장이 없다. Phase 1은 외부 라이브러리 없이 경량 자체 구현으로 충분.

```typescript
// 軽量i18n: キーから現在言語の文字列を返す。無ければjaへフォールバック
type Dict = Record<string, string>;

let current: Dict = {};   // 現在の言語の辞書
let fallback: Dict = {};  // 常にja（フォールバック用）

// 対応ロケール一覧
const SUPPORTED = ['ja', 'en', 'ko', 'zh-CN', 'zh-TW'];

// 端末言語からロケールを推定（対応外はja）
export function detectLocale(): string {
  const lang = navigator.language;            // 例: "ko", "zh-TW"
  if (SUPPORTED.includes(lang)) return lang;
  const base = lang.split('-')[0];            // 例: "zh"
  if (base === 'zh') return 'zh-TW';          // 既定は繁体。簡体判定は別途
  return SUPPORTED.includes(base) ? base : 'ja';
}

// 辞書を登録（fallbackには常にjaを渡す）
export function setDicts(currentDict: Dict, jaDict: Dict) {
  current = currentDict;
  fallback = jaDict;
}

// キーを翻訳。無ければja、それも無ければキー文字列を返す
export function t(key: string): string {
  return current[key] ?? fallback[key] ?? key;
}
```

> **현재 구현 상태**: 엔진 · 5개 사전 · 표시문자열 키화 완료. 단 `PreloadScene`에서 `setDicts(ja, ja)`로 **ja 고정**. `detectLocale()` 연결 · 타 언어 import · 선택 UI는 **Cycle 5c**에서.

## 7. 언어 선택 UX
- 최초 진입: `detectLocale()`로 기기 언어 자동 감지 → 매칭 없으면 `ja`
- 타이틀 화면 우상단 🌐 버튼에서 수동 변경 (현재 **자리만** 확보, 기능 미구현 → 5c)
- 선택값은 localStorage(`locale` 키)에 저장 → 다음 실행 시 우선 적용
- 우선순위: `localStorage.locale` > `detectLocale()` > `ja`

## 8. 폰트
- 한자권(ja / zh-CN / zh-TW) 자형 차이 → 언어별 웹폰트 또는 광역 폰트(Noto Sans CJK 계열).
- CJK 폰트는 용량이 큼 → **서브셋 / 동적 로드** 검토(상세 `30_에셋파이프라인`).
- en · 숫자는 공통 폰트로 처리.
- 벽지 티커(§13)는 4개 언어를 동시에 표시하므로 **ja · ko · zh 자형이 한 폰트 스택 안에서 모두 렌더**돼야 한다. 현재는 시스템 폰트 스택(`system-ui, "Hiragino Sans", "Noto Sans JP", sans-serif`)에 의존.

## 9. 이미지 L10N
- **전 언어 공통**: 글자 없는 캐릭터 그림 `char_<key>`, 타이틀 배경 `ui_title_bg`
- **언어별 분기(최소)**: 글자 박힌 이미지는 `<asset>__<locale>` (예: `logo_title__ja`)
- 현재 `logo_title__ja.png`만 존재하며 전 언어 공통 사용 중. 필요 시 `__ko` 등 후속 제작.
- 권장: 타이틀 로고 등 "진짜 그림 글자"만 분기, 나머지는 폰트 렌더로 대체.

## 10. 번역 워크플로우
1. 신규 텍스트 → `ja.json`에 키 + 값 추가(마스터)
2. 나머지 언어 파일에 같은 키 추가 · 번역
3. 미번역은 자동으로 `ja` 폴백 → 앱은 안 깨짐
4. 미번역 키 검출: ja 키 집합과 각 언어 키 집합 diff(스크립트) — 상세 `40_QA`

## 11. 검증 룰 (중요)
- **한글-금지 룰 적용 대상**: 코드 로직 · 주석 = `*.ts` · `*.sql` · `*.yaml` · `*.sh`
- **적용 제외 (표시 데이터)**:
  1. `src/locales/*.json` — 번역 데이터. `ko.json`엔 한국어, `zh-*`엔 중국어가 들어가는 게 정상.
  2. `index.html`의 `#wallpaper[data-words]` 속성값 — 벽지 티커에 흐를 다언어 문자열(§13). 값에 `#케시카스`가 포함되는 게 정상.
- 자동 검사 스크립트(`40` §9.1)는 `.ts/.sql/.yaml/.yml/.sh`만 스캔하므로 위 두 대상은 자동 제외된다. `.html`을 스캔 대상에 추가하지 말 것.
- **주의**: 위 예외는 **데이터 값**에만 적용된다. `index.html` 안의 **CSS 주석 · JS 주석 · 로직**은 여전히 일본어 주석 룰을 따른다.

## 12. 중국어 검수 현황 (출시 전 필수)
| 대상 | 출처 | 검수 필요 |
|---|---|---|
| `char.<key>.name` 11종 (zh-CN / zh-TW) | **Claude 초안** | ✅ 필요 |
| `name.default` (`匿名小鸡` / `匿名小雞`) | Claude 초안 | ✅ 필요 |
| `game.best` (`最高分`) | Claude 초안 (简繁 공통이라 비교적 안전) | △ 확인 권장 |
| 벽지 티커 `#可愛卡薯` | **자사 공식 로고 이미지 유래**(繁體). 타쿠 확인 완료 (2026-07-09) | ❌ 불필요 |

**중점 검수 항목** (타쿠는 중국어 미독해 → 원어민 확인 필요):
- `char.mammoth.name` 繁體: 현재 `猛瑪象` vs 표준 후보 `長毛象`
- `char.shrimp.name`: `こえびちゃん`의 「ちゃん」 애칭 뉘앙스가 중국어로 살지 않을 수 있음
- `char.seaslug.name`: `海蛞蝓`는 학술어라 과도하게 딱딱함

> 출시 전 `40` §7 L5/L6 테스트 시점에 일괄 검수.

## 13. 다언어 동시 표시 (벽지 티커)
- **위치**: `index.html`의 `#wallpaper` (캔버스 **바깥**, Phaser 관할 아님)
- **문구**: `data-words="#消しかす,#Keshikasu,#케시카스,#可愛卡薯"` (콤마 구분, 표시 시 ` ・ `로 연결)
- **성격**: 로케일 전환 대상이 **아니다**. 4개 언어를 항상 함께 흘려보내는 브랜드 장식이다. → L10N 키를 쓰지 않으며, `locales/*.json`에도 넣지 않는다.
- **변경 방법**: `data-words` 속성값 한 줄만 수정. 씬 코드 · 로케일 파일 무관.
- **접근성**: `aria-hidden="true"` (스크린리더 대상 제외), `prefers-reduced-motion: reduce` 시 애니메이션 정지.

## 14. 미해결
- 简体(zh-CN) / 繁體(zh-TW) 자동 분기 정밀화 (navigator.language만으론 부족할 수 있음)
- 중국어 캐릭터명 · 기본명 원어민 검수 (§12)
- CJK 폰트 용량 최적화 방식 확정 (`30`)
- 벽지 티커 폰트: 시스템 폰트 스택 의존 → ko/zh 자형이 기기별로 달라질 수 있음. 웹폰트 도입 시 재검토.
- 서버 표시명(name) 문자셋 · 길이 (`50`과 연계)
- 긴 문자열(독일어 등 향후) 대비 UI 레이아웃 가변성 (`40` 테스트)
