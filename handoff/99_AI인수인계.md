## 4. 작업 규칙 (반드시 준수)

### 4.1 언어 룰

  - ※ **예외(표시 데이터)**: `locales/*.json`의 값, `index.html`의 `data-words` 값. 각 언어 문자가 정상. 한글-금지는 코드 로직·주석(ts/sql/yaml/sh)에만 적용. (`25` §11)
- **대화(사용자): 한국어**
- **프롬프트(외부 LLM 호출): 영어**
- 코드 작성 후: 한글 자음(ㄱ-ㅎ) 검색 → 0건 확인.

### 4.2 5원칙
1. 가정 X (코드 안 보고 추측 X, 필요 시 파일 요청)
2. 최소 코드 (필요한 곳만 수정)

### 4.3 커뮤니케이션
- 트레이드오프 ≠ 작업 지시. 코딩 착수 전 **명시적 동의 필수**.
- **선택지 제시 단계에선 코드 미작성**: 선택지는 간결한 설명만으로 제시하고, 사용자가 고른 뒤에 그 안의 코드만 작성한다(토큰 절약). '착수 전 동의' 원칙은 유지.
- 한 번에 한 단계. 작은 사이클 ("하나하나 완성"). **파일 하나씩.**
- 할 일은 `[할 일 N]`으로 분리. 각 항목에 명령 / 위치 / 기대결과 / 분기 포함.
- 파일명 대소문자 정확히.
- **문서 통째 갱신은 완성본(아티팩트)으로 제공** — 변경점만 채팅에 흩뿌리지 말 것.
- **라이브러리 동작이 의심되면 추측하지 말고 실제 소스를 읽는다.** (Cycle 5c에서 `npm pack phaser@4.2.0` → 소스 확인으로 원인 특정)

## 6. 미결 과제

### 6.1 ★ Phaser 4 입력 판정 함정 (재발 방지 — 반드시 읽을 것)
Phaser 4.2.0 `src/input/InputManager.js`:
```js
pointWithinHitArea: function (gameObject, x, y) {
    //  Normalize the origin
    x += gameObject.displayOriginX;
    y += gameObject.displayOriginY;
    ...
}
```
`src/gameobjects/container/Container.js`:
```js
displayOriginX: { get: function () { return this.width * 0.5; } }
```

- **증상**: Container에 `setInteractive(new Phaser.Geom.Rectangle(-w/2, -h/2, w, h), Rectangle.Contains)`를 주면 **원점 보정이 두 번** 걸려 히트영역이 버튼 절반만큼 **좌상단으로 이동**한다.
  - 실측(220×84, 중심 225,440): 그려진 버튼 `x 115~335 / y 398~482` vs 실제 반응 `x 5~225 / y 356~440`. **겹침 = 버튼 면적의 1/4.**
  - 체감: "버튼을 여러 번 눌러야 반응한다" + "버튼 바깥을 눌러도 반응한다"
- **해결(Cycle 5c)**: `setSize(w, h)` 후 **`setInteractive({ useHandCursor: true })`**. Phaser가 `setHitAreaFromTexture()`로 `Rectangle(0, 0, width, height)`를 만들어 준다(공식 경로).
- **원칙**: **히트영역 좌표를 손으로 쓰지 않는다.** 객체 크기에서 파생시킨다. 5f 이후 새 버튼도 동일.
- **Text·Image는 무해**: `Origin` 컴포넌트를 정상 보유 → 기본 경로가 맞게 동작. (GameScene의 retry 버튼이 멀쩡했던 이유)
- **`pixelPerfect`는 Container에 불가**: 소스에 `console.warn('Cannot pixelPerfect test a Container.')`. 텍스처 기반 객체(Image/Sprite)만 가능.
- **`pixelPerfect`의 `alphaTolerance` 기본값 = 1**: 알파 1/255 이상이면 눌림 판정. **반투명 그림자를 PNG에 구워 넣으면 그림자도 눌린다.** 그림자는 별도 레이어로 분리할 것.

### 6.3 기타
- 밸런스 튜닝: 1~2단 크기차가 작음 (`merge_ladder` radius 조정) ← ⑤
- 합체 사다리 4~11단 실제 등장/난이도 검증
- **중국어 검수 미완**: 캐릭터명 11종 + `name.default` + `game.best` + (예정)`title.ranking` 초안 상태, 타쿠 중국어 미독해 (`25` §12)
  - ※ 벽지 문구 `#可愛卡薯`는 **자사 공식 로고 유래**라 검수 대상 아님(구분할 것)
- 효과음 라이선스 종류 미확정 (CC0 가정 — 출시 전 크레딧 표기 필요 여부 확인)
- **keepalive.yml 미생성**(`50` §8): Secrets는 이미 있으므로 파일만 추가하면 됨
- **벽지 `will-change` 30개**: 데스크톱에서 GPU 레이어 메모리 과다 우려(추정 100MB↑). `REPEAT = 4` → `3`으로 줄일 여지 있음. **단 실제 증상 미확인 → 백로그.** 저사양 기기 실측 후 판단
- **한글 검사 도구 주의**: `findstr /R "[가-힣]"`는 **쓰지 말 것**. 콘솔 코드페이지 변환으로 `??`(nullish) 줄을 전부 오탐한다. `Select-String -Pattern '[\uAC00-\uD7A3\u3130-\u318F]'` 또는 `40` §9.1 파이썬 스크립트를 쓴다.
- **바이너리 보호**: `.gitattributes` 미생성. png/wav CRLF 손상 위험. 안전상 추가 검토 권장.
