## 4. 작업 규칙 (반드시 준수)

### 4.1 언어 룰
- **코드 주석: 일본어 무조건** (한국어 단어 금지). 예) 「後ほど」「予定」「変更」「修正」「将来」.
  - ※ 이 규칙은 **코드 파일** 한정. 본 기획 / 사양 문서는 의도적으로 한국어로 작성.
  - ※ **예외(표시 데이터)**: `locales/*.json`의 값, `index.html`의 `data-words` 값. 각 언어 문자가 정상. 한글-금지는 코드 로직·주석(ts/sql/yaml/sh)에만 적용. (`25` §11)
- **대화(사용자): 한국어**
- **프롬프트(외부 LLM 호출): 영어**
- 코드 작성 후: 한글 자음(ㄱ-ㅎ) 검색 → 0건 확인.

### 4.2 5원칙
1. 가정 X (코드 안 보고 추측 X, 필요 시 파일 요청)
2. 최소 코드 (필요한 곳만 수정)
3. 필요한 곳만 (영향 범위 파악 후)
4. 성공 기준 정의 후 검증
5. 위치 명확화 (앞뒤 기존 코드 함께 제시)

### 4.3 커뮤니케이션
- 트레이드오프 ≠ 작업 지시. 코딩 착수 전 **명시적 동의 필수**.
- **선택지 제시 단계에선 코드 미작성**: 선택지는 간결한 설명만으로 제시하고, 사용자가 고른 뒤에 그 안의 코드만 작성한다(토큰 절약). '착수 전 동의' 원칙은 유지.
- 한 번에 한 단계. 작은 사이클 ("하나하나 완성").
- 할 일은 `[할 일 N]`으로 분리. 각 항목에 명령 / 위치 / 기대결과 / 분기 포함.
- 파일명 대소문자 정확히.
- **문서 통째 갱신은 완성본(아티팩트)으로 제공** — 변경점만 채팅에 흩뿌리지 말 것.

## 5. 용어집
- **케시카스**: Piyopiyo Studio 자체 IP. 음식 · 사물 약 30종 + 동물 약 8종.
- **머지(수박게임형)**: 같은 것끼리 합쳐 상위 단계로 키우는 메커닉.
- **합체 사다리(merge ladder)**: 합체 단계 순서표. 데이터로 분리.
- **PWA**: 설치형 웹앱. **Capacitor**: 웹 → 네이티브 래퍼.
- **MAU**: 월 활성 사용자. **RLS**: Supabase 행 단위 보안 정책.
- **데드라인**: 머지 플레이필드 상단 경계. 넘으면 게임오버.
- **L10N / i18n**: 다국어화. 표시 문자열을 키로 처리해 언어별 테이블에서 조회.
- **로케일(locale)**: 언어 코드(ja · en · ko · zh-CN · zh-TW). 폴백 = ja.
- **only-if-best**: 게임오버 시 **저장된 최고점을 초과할 때만** 서버 전송(egress 절약).
- **레터박스**: 화면 비율 차이로 게임 캔버스(450×800) 양옆에 생기는 빈 공간. 넓은 화면(데스크톱)에서 뚜렷.
- **벽지(wallpaper) / 사선 티커**: 캔버스 **바깥** 전화면 배경 장식(`index.html` `#wallpaper`). 레터박스 여백을 케시카스 문구 띠로 채운다. Phaser 관할 아님.
- **`prefers-reduced-motion`**: OS의 "동작 줄이기" 설정. 켜져 있으면 티커 애니메이션 정지(접근성).

## 6. 미결 과제
- **④ 타이틀 잔여**:
  - **언어선택 UI(🌐)** ← **다음(5c)**: detectLocale 연결 + 5개 언어 import + 선택 UI + localStorage `locale`
  - 랭킹 조회 표시(🏆): `fetchTop()` 호출 → 상위 N 표시
  - 이름 입력 UX: 최초 1회 입력 → localStorage `playerName` → `submitBest`에 전달(`50` §7.2)
- 벽지 씬별 테마 전환: `data-wp` 훅만 존재, 전환 로직 없음. 필요해지면 씬 진입 시 `document.documentElement.dataset.wp = '...'` 1줄
- 밸런스 튜닝: 1~2단 크기차가 작음 (`merge_ladder` radius 조정)
- 합체 사다리 4~11단 실제 등장/난이도 검증
- **중국어 검수 미완**: 캐릭터명 11종 + `name.default`(`匿名小鸡`/`匿名小雞`) + `game.best`(`最高分`) 초안 상태, 타쿠 중국어 미독해 (`25` §12).
  - ※ 벽지 문구 `#可愛卡薯`는 **자사 공식 로고 유래**라 검수 대상 아님(구분할 것).
- 효과음 라이선스 종류 미확정 (CC0 가정 — 출시 전 크레딧 표기 필요 여부 확인)
- **GitHub Secrets**: `SUPABASE_URL` · `SUPABASE_ANON_KEY` **등록 확인 완료**(2026-07-09). deploy.yml `env:` 매핑도 수정 완료 → 배포판 랭킹 정상.
- **keepalive.yml 미생성**(`50` §8): Supabase 7일 미사용 자동정지 방지 워크플로 미착수. Secrets는 이미 있으므로 파일만 추가하면 됨.
- **한글 검사 도구 주의**: `findstr /R "[가-힣]"`는 **쓰지 말 것**. 콘솔 코드페이지 변환으로 패턴이 `[?-?]`가 되어 `??`(nullish) 줄을 전부 오탐한다. `Select-String -Pattern '[\uAC00-\uD7A3\u3130-\u318F]'` 또는 `40` §9.1 파이썬 스크립트를 쓴다.
- 학습자료 갭 유의: Phaser 4 일부 API가 v3와 다름 (예: 바디 목록은 `world.getAllBodies()`)
