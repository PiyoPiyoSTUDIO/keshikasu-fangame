## 4. 실제 코드 구성 (현재 존재 파일)
- `src/main.ts` — 진입점
- `src/config.ts` — Phaser 설정 (씬: Preload → Game)
- `src/types.ts` — MergeTier / SaveData / ScoreRecord
- `src/vite-env.d.ts` — Vite型定義(`import.meta.env`用)
- `src/data/merge_ladder.ts` — 동물 11종 + 헬퍼(tierById, spawnableTiers)
- `src/services/i18n.ts` — 경량 i18n(detectLocale / setDicts / t, ja 폴백)
- `src/services/saveLocal.ts` — 自己ベストのlocalStorage入出力(loadLocalBest / saveLocalBest)
- `src/services/supabase.ts` — 匿名認証·スコアupsert·ランキング取得(ensureAnonSignIn / submitBest / fetchTop)
- `src/locales/ja.json`(마스터) · `en.json` · `ko.json` · `zh-CN.json` · `zh-TW.json` — 5개 언어 사전(17키: UI 4 + char 11 + `game.best` + `name.default`)
- `src/scenes/PreloadScene.ts` — 11종 이미지 + 효과음 3종 로드 + i18n 초기화(`setDicts(ja, ja)`) + 로딩 표시(키화)
- `src/scenes/GameScene.ts` — 코어 루프 전체(드롭·클램프·쿨타임·NEXT·합체·점수·팝·스쿼시·파티클·효과음·게임오버(키화)·다시하기 + 로컬 최고점 저장·표시 + Supabase only-if-best 전송)
- `public/assets/characters/char_*.png` — 11종 투명 PNG
- `public/assets/audio/sfx_drop.wav` · `sfx_merge.wav` · `sfx_gameover.wav` — 효과음 3종
- `.env` — Supabase 접속정보(`VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`). **gitignore 대상, 커밋 안 함**
- `.gitignore` — node_modules / dist / .env 등 제외
- `.github/workflows/deploy.yml` — 자동배포
- `vite.config.ts` · `tsconfig.json` · `index.html` · `package.json`

> **TDD(`20`)와의 차이**: BootScene / TitleScene / GameOverScene는 아직 미생성. 현재 게임오버는 GameScene 내 오버레이로 처리(추후 GameOverScene로 분리 가능).

> **dev 서버 주의**: `vite.config.ts`의 base는 `command === 'build' ? '/keshikasu-fangame/' : '/'`. 즉 **dev에선 base가 `/`**라 접속 주소는 `http://localhost:5173/` (서브경로 `/keshikasu-fangame/` 붙이면 SPA fallback으로 에셋이 HTML로 응답돼 깨짐). 빌드/배포 시에만 서브경로.

## 5. 미구현 / 다음 후보
- 타이틀 화면 (TitleScene: START · 랭킹 · 언어선택) ← **다음 작업(④)**
