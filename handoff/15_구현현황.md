## 4. 실제 코드 구성 (현재 존재 파일)
- `index.html` — 진입 HTML. **캔버스 바깥 벽지 레이어(`#wallpaper`) + 사선 티커 CSS/JS 인라인 포함**(Cycle 5b). `#game`이 Phaser 마운트 지점
- `src/main.ts` — 진입점
- `src/config.ts` — Phaser 설정 (씬: **Preload → Title → Game**)
- `src/types.ts` — MergeTier / SaveData / ScoreRecord
- `src/vite-env.d.ts` — Vite型定義(`import.meta.env`用)
- `src/data/merge_ladder.ts` — 동물 11종 + 헬퍼(tierById, spawnableTiers)
- `src/services/i18n.ts` — 경량 i18n(detectLocale / setDicts / t, ja 폴백)
- `src/services/saveLocal.ts` — 自己ベストのlocalStorage入出力(loadLocalBest / saveLocalBest)
- `src/services/supabase.ts` — 匿名認証·スコアupsert·ランキング取得(ensureAnonSignIn / submitBest / fetchTop)
- `src/locales/ja.json`(마스터) · `en.json` · `ko.json` · `zh-CN.json` · `zh-TW.json` — 5개 언어 사전(**18키**: UI 4 + char 11 + `game.best` + `name.default` + `title.start`)
- `src/scenes/PreloadScene.ts` — 11종 이미지 + 효과음 3종 + 타이틀 배경·로고 2종 로드 + i18n 초기화(`setDicts(ja, ja)`) + 로딩 표시(키화). 로드 후 TitleScene으로 전이
- `src/scenes/TitleScene.ts` — 타이틀 화면(배경 cover / 로고 바운스 / START 세련화 / 돼지·토끼 바운스 / 최고점 표시 / 🏆·🌐 자리). START 탭 → GameScene
- `src/scenes/GameScene.ts` — 코어 루프 전체(드롭·클램프·쿨타임·NEXT·합체·점수·팝·스쿼시·파티클·효과음·게임오버(키화)·다시하기 + 로컬 최고점 저장·표시 + Supabase only-if-best 전송)
- `public/assets/characters/char_*.png` — 11종 투명 PNG
- `public/assets/audio/sfx_drop.wav` · `sfx_merge.wav` · `sfx_gameover.wav` — 효과음 3종
- `public/assets/ui/ui_title_bg.png` — 타이틀 배경(초원 씬, 글자 없음 → 전 언어 공통)
- `public/assets/logo/logo_title__ja.png` — 타이틀 로고(消しかす, ja). 현재 전 언어 공통 사용
- `.env` — Supabase 접속정보(`VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`). **gitignore 대상, 커밋 안 함**
- `.gitignore` — node_modules / dist / .env 등 제외
- `.github/workflows/deploy.yml` — 자동배포
- `vite.config.ts` · `tsconfig.json` · `package.json`

> **TDD(`20`)와의 차이**: BootScene / GameOverScene / `objects/Keshi.ts` / `systems/*` 는 아직 미생성. 게임오버는 GameScene 내 오버레이로 처리(추후 GameOverScene로 분리 가능).

> **dev 서버 주의**: `vite.config.ts`의 base는 `command === 'build' ? '/keshikasu-fangame/' : '/'`. 즉 **dev에선 base가 `/`**라 접속 주소는 `http://localhost:5173/` (서브경로 `/keshikasu-fangame/` 붙이면 SPA fallback으로 에셋이 HTML로 응답돼 깨짐). 빌드/배포 시에만 서브경로.

> **에셋 로드 실패 함정(Windows)**: 존재하지 않는 에셋을 요청하면 dev 서버가 `index.html`을 대신 반환 → Phaser가 이미지로 못 읽어 `Failed to process file: image "..."` 발생(404가 아님). Cycle 5a에서 로고가 `logo_title__ja.png.png`(확장자 중복 저장)로 저장돼 재현됨. Windows 확장자 숨김 때문에 이미 `.png`인 파일에 `.png`를 또 붙이는 실수 주의. `dir` 로 실제 파일명 확인 → `ren` 으로 교정.

> **벽지 = 캔버스 바깥**: `#wallpaper`는 Phaser 관할이 아니다. 색·속도·문구 변경은 **`index.html`의 CSS 변수 / `data-*` 속성**만 손대면 되고, 씬 코드는 건드리지 않는다.
