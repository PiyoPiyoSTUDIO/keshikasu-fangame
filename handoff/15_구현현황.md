| 위상 스태거 | `animationDelay = calc(var(--wp-dur) * -{(i % 5) * 0.17})` | JS |
| 루프 무이음 | 동일 텍스트 2본 나열 + `translateX(-50%)` | `@keyframes wp-scroll` |
| 텍스트 반복수 | `REPEAT = 4` (띠 1본이 화면폭을 확실히 초과) | JS |
| z-index | 벽지 `0` / `#game` `1` | CSS |
| 입력 | `pointer-events: none` | `#wallpaper` |
| 모션 감축 | `@media (prefers-reduced-motion: reduce)` → `animation: none` | CSS |

> **성능 백로그**: `.wp-track` 30개에 `will-change: transform`이 상시 적용됨. 데스크톱에서 GPU 레이어 메모리가 커질 수 있다(추정 100MB↑). 무이음 루프에 필요한 최소 조건은 `1본 폭 ≥ 160vmax`이므로 `REPEAT`를 `3`으로 줄일 여지가 있다. **다만 실제 증상은 미확인 → 손대지 않음.**

## 4. 실제 코드 구성 (현재 존재 파일)
- `index.html` — 진입 HTML. 캔버스 바깥 벽지 레이어(`#wallpaper`) + 사선 티커 CSS/JS 인라인 포함. `#game`이 Phaser 마운트 지점
- `src/main.ts` — 진입점
- `src/config.ts` — Phaser 설정 (씬: **Preload → Title → Game**)
- `src/types.ts` — MergeTier / SaveData / ScoreRecord
- `src/vite-env.d.ts` — Vite型定義(`import.meta.env`用)
- `src/data/merge_ladder.ts` — 동물 11종 + 헬퍼(tierById, spawnableTiers)
- `src/services/i18n.ts` — 경량 i18n(detectLocale / setDicts / t, ja 폴백). **`detectLocale()`엔 이미 `localStorage.locale` 우선순위가 들어 있음**
- `src/services/saveLocal.ts` — 自己ベストのlocalStorage入出力(loadLocalBest / saveLocalBest)
- `src/services/supabase.ts` — 匿名認証·スコアupsert·ランキング取得(ensureAnonSignIn / submitBest / fetchTop)
- **`src/ui/tapFeedback.ts`** — **공용 탭 피드백 헬퍼(`attachTapFeedback`). Cycle 5d 신설. `ui/` 폴더도 이때 신설**
- `src/locales/ja.json`(마스터) · `en.json` · `ko.json` · `zh-CN.json` · `zh-TW.json` — 5개 언어 사전(**18키**)
- `src/scenes/PreloadScene.ts` — 이미지·효과음 로드 + i18n 초기화(`setDicts(ja, ja)`) + 로딩 표시. 로드 후 TitleScene으로 전이
- `src/scenes/TitleScene.ts` — 타이틀 화면. START는 `setSize` + `setInteractive({useHandCursor:true})` + `attachTapFeedback`
- `src/scenes/GameScene.ts` — 코어 루프 전체 + 로컬 최고점 저장·표시 + Supabase only-if-best 전송
- `public/assets/characters/char_*.png` — 11종 투명 PNG
- `public/assets/audio/sfx_drop.wav` · `sfx_merge.wav` · `sfx_gameover.wav` — 효과음 3종
- `public/assets/ui/ui_title_bg.png` — 타이틀 배경(초원 씬, 글자 없음 → 전 언어 공통)
- `public/assets/logo/logo_title__ja.png` — 타이틀 로고(消しかす, ja). 현재 전 언어 공통 사용
- `.env` — Supabase 접속정보. **gitignore 대상, 커밋 안 함**
- `.gitignore` · `.github/workflows/deploy.yml` · `vite.config.ts` · `tsconfig.json` · `package.json`

> **TDD(`20`)와의 차이**: BootScene / GameOverScene / `objects/Keshi.ts` / `systems/*` 는 아직 미생성. 게임오버는 GameScene 내 오버레이로 처리.

> **dev 서버 주의**: `vite.config.ts`의 base는 `command === 'build' ? '/keshikasu-fangame/' : '/'`. 즉 **dev에선 base가 `/`**라 접속 주소는 `http://localhost:5173/`.

> **에셋 로드 실패 함정(Windows)**: 존재하지 않는 에셋을 요청하면 dev 서버가 `index.html`을 대신 반환 → Phaser가 `Failed to process file: image "..."` 발생(404가 아님). Windows 확장자 숨김으로 `.png.png`가 생기지 않도록 `dir`로 실제 파일명 확인.

> **⭐ Phaser 4 입력 판정 함정**: Container에 히트영역 Rectangle을 **손으로 넘기면 안 된다.** `displayOrigin`(=width/2) 보정이 이중으로 걸려 판정이 좌상단으로 밀린다. 상세·재현값 → `99` §6.1

> **벽지 = 캔버스 바깥**: `#wallpaper`는 Phaser 관할이 아니다. 색·속도·문구 변경은 `index.html`의 CSS 변수 / `data-*` 속성만.

- 중국어 캐릭터명 검수 미완(`25` §12)

## 6. 알려진 무해 경고 (콘솔)
- `favicon.ico 404` — 아이콘 미설정. 무해. PWA 아이콘 단계(`60`)에서 해결.
- `chunk size > 500KB` (빌드 시) — Phaser 엔진 용량이라 무해.

## 7. 갱신 규칙
- 기능 추가/수정 사이클마다 §2~§5 갱신. 튜닝값 바뀌면 §3 즉시 반영.
- 캔버스 바깥(HTML/CSS) 튜닝값은 §3.2에 분리 기록.
- 브랜드 컬러 실측값은 §3.3에 기록.
