# 60. 빌드 / 배포

- **문서 버전**: v1.0
- **최종 수정**: 2026-06-24
- **범위**: 로컬 개발 → 빌드 → PWA → GitHub Pages 배포 → (차후) 앱화.

---

## 1. 목적
무료 스택으로 iOS/Android 브라우저에 즉시 배포. 동일 코드로 차후 앱화 보존.

## 2. 로컬 개발
```bash
npm install        # 依存をインストール
npm run dev        # Vite開発サーバー（ホットリロード）
```
- 환경변수 파일 `.env` (gitignore 대상):
```bash
# Supabase接続情報（VITE_接頭辞でクライアントに露出。anonキーはRLS前提で公開可）
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

## 3. 빌드
```bash
npm run build      # dist/を生成
```
- GitHub Pages 서브경로 배포 → `base` 설정 필요:
```typescript
import { defineConfig } from 'vite';

// GitHub Pagesのサブパス配信に合わせてbaseを設定する
export default defineConfig({
  base: '/keshikasu-fangame/',   // リポジトリ名に合わせる
  build: { outDir: 'dist' },
});
```

## 4. PWA (설치형 / 오프라인)
- `manifest.json` + 서비스워커. `vite-plugin-pwa` 권장(서비스워커 자동 생성).
- iOS 주의: `apple-touch-icon` 필요, 일부 PWA 기능 제약.
```json
{
  "name": "Keshikasu Merge",
  "short_name": "Keshikasu",
  "start_url": ".",
  "display": "standalone",
  "background_color": "#fce0e3",
  "theme_color": "#fce0e3",
  "icons": [
    { "src": "assets/ui/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "assets/ui/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```
> manifest의 `name`은 단일 값이라 언어별 분기가 어려움 → 중립(영문) 또는 `ja` 기준으로. 게임 내 텍스트는 L10N(`25`)으로 별도 처리.

## 5. 배포 (GitHub Pages)
```yaml
# mainブランチへのpushでビルドしGitHub Pagesへデプロイする
name: deploy
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci          # 依存をクリーンインストール
      - run: npm run build   # dist/を生成
        env:
          VITE_SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          VITE_SUPABASE_ANON_KEY: ${{ secrets.SUPABASE_ANON_KEY }}
      - uses: actions/upload-pages-artifact@v3
        with: { path: dist }
      - uses: actions/deploy-pages@v4
```
> 액션 버전(@v4 등)은 배포 시점 최신 안정판으로 확인.

## 6. 환경변수 / 시크릿
- 빌드 시 `VITE_` 변수만 클라이언트 번들에 주입됨.
- anon 키는 공개 가능(RLS 전제). **service_role 키는 절대 클라이언트/빌드에 넣지 않음.**
- GitHub 저장소 Secrets에 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 등록 (키프얼라이브 `50`과 공유).

## 7. 차후 앱화 (Capacitor)
```bash
npm install @capacitor/core @capacitor/cli   # 将来：アプリ化の準備
npx cap add android
npx cap add ios                              # iOSビルドにはMacが必要
```
- 웹 빌드(`dist`)를 네이티브 셸로 감싸 스토어 배포 가능. **차후** 단계.
